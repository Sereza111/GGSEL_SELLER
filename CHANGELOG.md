# История изменений

## 1.0.0 — 2026-11-11

Первый публичный выпуск GGSEL SELLER в самостоятельном репозитории.

### Добавлено

- Главное меню с разделами чатов, уведомлений, команд покупателей, конфигурации, состояния и плагинов.
- Обнаружение переписок через API чатов независимо от списка последних продаж.
- Ссылки на темы покупателей и подсказки для отправки ответа.
- Переключатель уведомлений о новых сообщениях и время последних успешных проверок API.
- Экспорт конфигурации в JSON и импорт с проверкой, предпросмотром, подтверждением и резервной копией.
- Собственный интерфейс Python-плагинов команд покупателей с включением из Telegram, ограничением времени выполнения и обработкой ошибок.
- Установка через Docker Compose с постоянным хранением данных.
- Документация установки, управления и разработки плагинов.

### Исправлено

- Ввод команд с `/` и `!` при настройке автоответов, в том числе внутри темы покупателя.
- Отмена редактора и переходы между настройками без случайной отправки введённого текста покупателю.
- Обработка автора сообщения: сообщения продавца, удалённые сообщения и сообщения неизвестного автора не запускают автоответы.
- Повторный просмотр истории через `/history` и импорт истории без ответов на старые команды.
- Повторное использование темы при обнаружении заказа после переписки.
- Применение настроенных интервалов опроса.

### Сохранено

- Мониторинг заказов и отзывов, текстовые ответы через темы Telegram, баланс продавца и правила автоответов.
- SQLite для истории и состояния доставки; проверка разрешённых операторов по Telegram ID.

### Ограничения выпуска

- Ответы покупателю передаются текстом; вложения отправляются через кабинет GGsel.
- Плагины Cardinal напрямую несовместимы с интерфейсом GGsel.
- Первая загрузка истории не предназначена для запуска команд из старой переписки.
