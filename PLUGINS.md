# Плагины GGsel-бота

Бот поддерживает собственные Python-плагины команд покупателей. Плагины Cardinal
не совместимы с этим интерфейсом: у них другие события и API.

Для обычного ответа на `!help`, `/help` или другую фразу Python не нужен:
используйте «Команды покупателя / Автоответы» в Telegram. Плагины нужны для
дополнительной обработки текста.

## Установка

Положите два файла в `/data/plugins` контейнера (папка находится в постоянном
томе; при необходимости создайте её). Другой путь задаётся переменной
`PLUGINS_DIR`. Пример `help_command.py` есть в `plugins_examples/` и сам по себе
не установлен и не включён.

Файл `help_command.json`:

```json
{
  "id": "help_command",
  "name": "Ответ на !help",
  "version": "1.0",
  "module": "help_command.py"
}
```

Файл `help_command.py`:

```python
def on_message(message: str):
    if message.strip().casefold() == "!help":
        return "Здравствуйте! Опишите ваш вопрос в этом чате."
    return None
```

Откройте `/menu` → «Плагины» и включите установленный плагин. Настройка сохраняется
в SQLite. До включения бот читает только JSON-манифест и Python-файл как данные,
не выполняя Python-код. Изменение файлов требует повторного включения плагина.

## Контракт

`on_message(message: str)` получает текст нового сообщения покупателя и возвращает
строку до 4000 символов либо `None`. Также допускается `async def on_message`.
Возвращённый текст отправляется покупателю обычной очередью автоответов.
История и сообщения продавца не вызывают автоответы. Встроенные правила ответа
имеют приоритет; если они не совпали, используются плагины в порядке ID.

Плагин запускается в отдельном процессе без переменных окружения с ключами API
и токеном Telegram. Один вызов ограничен двумя секундами; общий бюджет перебора
плагинов — пять секунд. Одновременно работает один процесс; можно включить до
четырёх плагинов из первых 16 манифестов по имени. Объекты бота, API и базы данных
в обработчик не передаются. Процесс не сохраняет состояние между вызовами.
При ошибке плагин пропускается до повторного включения; причина видна в меню.

Это **доверенный серверный Python-код**, а не песочница: он имеет права процесса
контейнера и может самостоятельно обращаться к файлам и сети. Устанавливайте
свой или проверенный код. Загрузка и выполнение Python через сообщения
покупателей или вложения Telegram не поддерживаются.
